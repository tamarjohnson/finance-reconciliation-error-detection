# Finance Reconciliation & Error-Detection Portfolio

**Purpose:** Demonstrate accounting judgement using a small, fictional bank-reconciliation case study.

**Privacy note:** All names, dates, account details, and amounts are fictional. No employer or client records are included.

## What this project demonstrates
- Matching bank statement activity to an accounting register
- Identifying missing entries, timing differences, and potential duplicates
- Investigating amount discrepancies using source documents
- Recommending documented corrections and control improvements
- Explaining accounting reasoning clearly

## Files
- `bank_statement.csv` — fictional bank statement activity
- `quickbooks_register.csv` — fictional accounting-system register
- `reconciliation_analysis.xlsx` — exceptions and recommended actions
- `findings_summary.md` — written findings and controls

## Method
1. Confirm the account, period, and opening balance.
2. Match transactions by date, description, and amount.
3. Separate timing differences from errors.
4. Trace exceptions to source documents.
5. Recommend corrections only after verification and approval.
6. Re-run the reconciliation and retain an audit trail.

This is a demonstration exercise, not an audit opinion or advice for a real entity.
